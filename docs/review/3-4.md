- **Physics model (`src/core/physics/models/transformerParallel.ts`)**: Registered under `'transformerParallel'` in `src/core/physics/registry.ts`.
  - **Stage 1 (Polarity Check, `stageMode: 1`)**: Parallel HV primaries (`txA`, `txB`) via 5 kVA variac (`Rs = 0.15 Ω`). Hidden polarity flip on `txB` (`txB.S1` non-dotted, `txB.S2` dotted). Series-opposition joins (`txA.S1–txB.S2` or `txA.S2–txB.S1`) read `~0.13–0.38 V` on `vpol`; series-aiding (`txA.S1–txB.S1`) reads `~230 V` (`V1/2.0000 + V1/2.0023`) and fails validation with feedback.
  - **Stage 2 (Load Sharing, `stageMode: 2`)**: Complex nodal solver `VL = (EA/ZA + EB/ZB) / (1/ZA + 1/ZB + 1/RL)` with `EA = V1/2.0000`, `EB = V1/2.0023`, `ZA = 0.150 + j0.220 Ω`, `ZB = 0.0882 + j0.1322 Ω`, `WA = Re(VL * conj(IA))`, `WB = Re(VL * conj(IB))`, and primary sag `V1 = Vset - I1 * 0.15` (`I1 = |IA|/2 + |IB|/2.0023 + (0.35 + 0.52)*(V1/230)`).
  - Faults: `wattmeterFaults` for `wmA` and `wmB`, `amA`/`amB`/`amL` across load (`short`), `ammeters-across-each-other` (`short`), `live-neutral-short`, `secondary-bus-short`, aiding secondary join or swapped-polarity parallel (`short`, trips MCB), and load switched on before polarity is fixed (`loadBeforePolarity`, trips MCB).
- **Registry (`src/core/experiments/registry.ts`)**: `ex3.4` registered and marked `available: true`.
