## Assumptions & Decisions
- **Stage-scoped meter & wattmeter parameters (`StageDef.componentParams`)**: Exp 3.2 reuses the same `wm`, `vm`, `am` component IDs (`wm.M`, `vm.A`, `am.IN`) across both stages with different ranges/PF per stage. Added optional `componentParams` overrides on `StageDef` so each stage configures `wm`, `vm`, and `am` ranges/PF cleanly without duplicating terminal prefixes.
- **Stage 2 source resistance (`Rs_sc = 0`)**: The prompt specifies supply sag `V = Vset - Io * 0.3` for Stage 1 and `Isc = V / |Zeq|` for Stage 2. Setting `Rs_sc: 0` in Stage 2 ensures `vm` reads the applied variac setting directly (`9.27 V` at `8.70 A`) while keeping `Rs: 0.3` active in Stage 1.
- **Bisection on overcurrent trip (`findVariacForTargetV1`)**: Because Stage 2's `0–30 V` variac exceeds the `125%` overcurrent trip threshold (`~11.58 V`) above midpoint, `findVariacForTargetV1` treats `mcbTripped === true` as `Infinity` (above target) so automated bisection converges cleanly to `8.70 A` (`~9.3 V`).
